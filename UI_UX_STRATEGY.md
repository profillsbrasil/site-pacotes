# Plano de Refatoração UI/UX - DuNort Premium

## Objetivo
Transformar a interface atual (Literal Organic) em uma experiência de **Organic Luxury**, elevando a percepção de marca e refinando a jornada do usuário.

## 🎨 Identidade Visual
- **Paleta:** Toasted Nut, Deep Sage, Warm Linen, Champagne Gold.
- **Tipografia:** Serif para títulos (Elegância), Sans para corpo (Modernidade).
- **Estilo:** Glassmorphism, Soft UI, Bento Grids.
